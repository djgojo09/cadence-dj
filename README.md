# Interview Practice Hub

Build a polished AI interview practice website with voice functionality. Include a welcoming landing page and an interview workspace where users can choose a role and experience level, start a voice interview, view live transcript, and receive AI feedback with scores and improvement tips. Make it responsive and professional. Enable Lovable Cloud for user progress and interview history, and use Lovable AI for feedback. Use a clear microphone-permission explanation before voice input.

This project was built with [Lovable](https://lovable.dev).
